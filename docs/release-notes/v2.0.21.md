### ✨ New Features / 新增功能

- **模型同步接入网关定义层元数据**: 同步时一并拉取 `GET /api/v1/admin/models` 的展示属性，
  `context_window` / `max_output_tokens` / `tool_calling` / `image_input` / `multimodal` 写入 `portal_models`。
  三态映射（unknown → NULL，不写 false/0），UPSERT 用 `COALESCE(EXCLUDED, 原值)`，网关没填时不清空管理端手填值。
- **新增 `getSmartRoutingPolicy()`**: 读取网关智能路由策略 `GET /api/v1/admin/smart-routing/policy`，
  返回 `configured` / `enabled` / `autoModelName` / 简单-复杂模型组 ID / 路由阈值等字段。
  用途一是判断智能路由是否开启（管理域 token 即可，不需要用户 Key），
  二是取虚拟模型的真实名称 —— 该名称由网关侧策略决定、可被改写，**不恒为 `auto`，门户不做硬编码**。
  为后续虚拟模型 / 智能路由落地预留接口。
- **门户用户名支持中文**: 注册允许中文用户名，网关侧自动生成唯一 ASCII 名，并以 `gateway_user_id` 关联，
  避免影响网关侧账号约束。
- **默认资源组展示全员成员**: 资源组详情对默认组返回全部非超管用户并补 `status` 字段，
  页面由说明卡改为「说明卡 + 只读全员列表」；停用用户标「已停用」但不过滤（授权保存是整表覆盖，过滤会静默删授权）。

### ⚙️ Enhancements / 功能优化

- **网关分流判据改以 DB 为准**: 新增 `readProviderName(pool)`，只读 DB、不 init 适配器、不抛错。
  修复进程内缓存未建立（刚启动 / 刚切 provider / init 失败）时回落 `1panel`，导致模型广场被 1Panel 数据覆盖、
  授权按 1Panel 表算出现 `allowed = null` 全公开兜底、Key 增删改误调 1Panel 产生幽灵记录的问题。
- **网关统计限流退避**: 逐日趋势改为低并发（3）+ 批次间隔 + 503 指数退避（最多 3 次），失败的天补零不丢数据；
  增加趋势总时限，避免整段空白。
- **恢复模型同步的 User API Key 配置**: 模型同步优先走 `/v1/models`。
- **个人中心统计口径对齐网关控制台**: 趋势卡片与月份筛选常驻。
- **构建链提速**: 新增 `Dockerfile.portal`，skillctl 二进制复用已发布产物、不再拉 Go 镜像；
  后端去掉 `python3/make/g++` 工具链（bcrypt@6 自带 glibc/musl 预编译二进制）。镜像构建从 20+ 分钟降到约 90 秒。

### 🛠️ Bug Fixes / 问题修复

- **安全：ILIKE 通配符越权**（重要）: 登录/查重/后台搜索把用户输入直接当 LIKE 模式，而注册正则允许下划线，
  `_` 既是合法用户名字符又是单字符通配符 —— 库中存在 `a_c` 时，用 `abc` + `a_c` 的密码即可登录进 `a_c` 账号；
  输入 `%` 更可命中全部用户。新增 `server/lib/sql-like.js` 的 `escapeLike()` 转义 `\ % _`，应用于 7 处。
- **登录不再强制小写用户名**: `sanitizeUsername()` 的 `toLowerCase()` 让「精确匹配优先」永远只命中全小写账号，
  大小写重名账号（如 `ZhaoLeiBo` / `zhaoleibo`，密码不同）输入正确密码仍返回 401。登录改用 trim 后的原始输入，
  注册仍统一小写；歧义提示更明确。
- **清理网关侧已删除的用户组缓存**: 原软删条件 `UPDATE ... AND enabled = TRUE`，而停用组 `enabled` 本就是 FALSE，
  永不匹配，幽灵组长期残留。改为按引用分流：无 `portal_users` 引用 → 物理删除；有引用 → 保留并置 `enabled = FALSE`
  （`permission.js` 在组行缺失时 `return null` 表示全公开，物理删会让受限用户看到全部模型）。
