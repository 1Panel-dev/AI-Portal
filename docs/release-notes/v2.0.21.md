### ✨ New Features / 新增功能

- **模型广场展示模型属性**：同步网关模型定义层的上下文窗口、最大输出、工具调用、图片输入、多模态，网关未提供时保持为空。
- **支持智能路由策略**：读取网关的智能路由开关与虚拟模型名（名称以网关返回为准，不硬编码）。
- **用户名支持中文**：注册时网关侧自动生成唯一 ASCII 名并关联。
- **默认资源组展示全员成员**，并标注已停用用户。

### ⚙️ Enhancements / 功能优化

- **网关分流判断改以数据库配置为准**，修复刚启动/切换网关时误走 1Panel，导致模型串源、授权失效。
- **统计趋势限流退避**，被限流的天补零，图表不再整段空白。
- **模型同步优先走 `/v1/models`**，恢复同步用 API Key 配置。
- **个人中心统计口径对齐网关控制台**。
- **镜像构建提速**：从 20+ 分钟降到约 90 秒。

### 🛠️ Bug Fixes / 问题修复

- **安全：修复用户名通配符越权**（重要）。登录/搜索把输入直接当 LIKE 模式，`_` 与 `%` 可匹配他人甚至全部用户名。已统一转义。
- **修复大小写重名账号无法登录**：输入正确密码仍返回 401。
- **修复网关侧已删除的用户组在门户残留**，同步时按是否被引用区分物理删除与停用。

### 🔧 升级说明

- 无需手工迁移；下次网关同步会自动清理残留用户组。
- 登录用户名**区分大小写**，新建用户仍统一小写。

```
docker pull 1panel/ai-portal:v2.0.21
```
