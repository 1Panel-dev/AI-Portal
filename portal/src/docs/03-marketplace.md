# Skill 广场

在 Skill 广场中你可以：

- 按**标签**筛选技能（左侧栏，点击标签名切换）
- 查看当前开放的 **1Panel** 来源技能
- 按下载量、发布时间、评分排序
- 点击技能卡片查看详情和安装方式

![Skill 广场筛选栏 + 卡片网格](/docs/img/marketplace-grid.png)

## 标签筛选

页面左侧为标签栏，展示当前可见技能适用的标签及数量。点击标签名即可只看带有该标签的技能，再次点击取消筛选。

标签数量按你的资源权限过滤——没有权限查看的技能不会计入标签统计，因此不同用户看到的标签及数量可能不同。

## 来源说明

当前仅开放 1Panel 来源：从 1Panel 企业版 Skills Hub 同步过来的官方技能。

本地来源暂不开放，后续版本再加入。
